## 4. Riesgos de seguridad alojada: avisos actuales, no alarmas inventadas

**Metadatos consultados directamente 19/11 sin inspeccionar datos personales:**
- Supabase `biomotors-taller` ACTIVE_HEALTHY y PostgreSQL 17.11; **12/12 tablas públicas tienen RLS**, solo **9/12 FORCE**. Es necesario revisar las otras tres según actor/grants, pero **FORCE no es requisito universal** para que una tabla tenga RLS efectiva.
- Esquemas `bt_cp05_private` (**3**) y `bt_platform_private` (**5**): todas las **8/8 RLS+FORCE**, **sin grants SELECT directos a anon/authenticated**. El asesor marca `rls_enabled_no_policy` **INFO** en las ocho: coincide con diseño privado **deny by default**, **no instalar políticas permisivas para eliminar el aviso**.
- Asesor marca **6 WARN** `authenticated_security_definer_function_executable` para RPC de Creador/planes; según contratos, **EXECUTE para `authenticated` es intencional** y los procedimientos deben validar Creador, membresía, AAL2 y permisos por servidor. **No están certificados por este aviso ni es correcto revocarlos a ciegas**. La auditoría funcional de estas seis funciones con roles cruzados/denegación real sigue pendiente.
- Asesor marca **WARN** `auth_leaked_password_protection`: **protección de contraseñas filtradas desactivada**. Es una mejora pendiente de habilitación/revisión de disponibilidad del plan.
- Buckets Storage **0**; Edge Function activa `bt-owner-onboarding` con `verify_jwt=true`. No equivale a comprobar todos sus flujos contra ataques.
- GitHub `public` por permiso temporal del propietario, **no declaración de que se examinaron todas las revisiones históricas en busca de secretos**. Requiere decisión del titular y, en caso de filtración efectiva, rotación tras evaluación. No cambiar visibilidad sin autorización.
- Workflow `bt-encrypted-backup.yml` es **manual**, requiere `confirm_database_export=true`; código actual admite exportación aun con repo público **solo con un segundo `confirm_public_repository_export=true`**. Una descripción anterior que diga «nunca exporta si está público» no describe el control actual. No usar esta posibilidad sin autorización explícita y revisar riesgo de logs/exposición.
- Render sigue `LIVE` en `d8d6ed99`. Candidatas de archivo PDF y correo CP05/LIVE-02/COM-A-D continúan sin instalar/activar; no afirmar que Ignacio pueda usarlas en producción.

**Referencias de advertencias, sin ejecutar remedios:** [RLS sin políticas (informativo)](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy), [RPC SECURITY DEFINER (revisión de intención)](https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable), [protección de contraseñas filtradas](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection).
